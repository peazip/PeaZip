=== about text group ===

EXTRAIR ARQUIVO(S) COMPACTADO(S)
Do sistema 
- clique com o botão direito no(s) arquivo(s) compactado(s) e, no menu de contexto do sistema, clique em "Extrair aqui" ou "Extrair aqui (nova pasta inteligente)" para extrair sem nenhuma interação adicional. A opção Nova pasta inteligente cria uma nova pasta de nível superior somente quando necessário, quando a raiz do arquivo compactado contém mais de um arquivo ou pasta.
- caso contrário, use a entrada de menu "Extrair..." para ter mais opções: caminho de saída, senha, extrair arquivos para um novo diretório, optar por ignorar, renomear ou sobrescrever arquivos existentes, etc.

Abra um arquivo compactado no PeaZip, por exemplo, com um clique duplo, ou arraste um arquivo compactado para a janela ou ícone do PeaZip
- clique em "Extrair" na barra de ferramentas ou no menu de contexto para extrair apenas os objetos selecionados por meio do diálogo de confirmação, que permite definir todas as opções (caminho de saída, senha, política de nomenclatura, extrair para um novo diretório, etc.)
- arraste arquivos e pastas para o destino desejado; apenas o conteúdo selecionado será extraído (para mais informações, consulte o capítulo sobre arrastar e soltar no PeaZip)
- clique no botão suspenso de extração rápida à direita de "Extrair" na barra de ferramentas; ele permite extrair diretamente o arquivo compactado inteiro para os destinos mais comuns (ignorando o diálogo de confirmação) e definir as opções mais importantes; atalhos de teclado: Ctrl+E (ou F12) extrai o arquivo compactado inteiro, solicitando o diretório de saída; Ctrl+Alt+E extrai o arquivo compactado na sua pasta atual; Ctrl+Shift+E extrai para a área de trabalho; Ctrl+Alt+Shift+E extrai para documentos; Ctrl+0 extrai para o caminho anterior; Ctrl+1..8 extrai para o caminho do marcador 1..8 (se definido)

Abra o PeaZip, selecione um ou mais arquivos compactados e clique em "Extrair" na barra de ferramentas ou no menu de contexto, ou use os destinos de extração rápida conforme explicado no ponto anterior.

EXTRAIR APENAS OBJETOS SELECIONADOS DO ARQUIVO COMPACTADO
Abra um arquivo compactado no PeaZip, por exemplo, com um clique duplo, ou arraste um arquivo compactado para a janela ou ícone do PeaZip
- clique em "Extrair" na barra de ferramentas: apenas os itens selecionados serão extraídos
- arraste arquivos e pastas para o destino desejado; apenas o conteúdo selecionado será extraído
- clique com o botão direito e, no grupo "Extrair" do menu de contexto, clique em "Extrair selecionados" (para extrair apenas os itens selecionados) ou "Extrair exibidos" (para extrair o conteúdo do diretório atual ou do filtro de pesquisa atual)

INSERIR UMA SENHA PARA NAVEGAR OU EXTRAIR UM ARQUIVO COMPACTADO
Clique no ícone de cadeado para inserir uma senha e, opcionalmente, um arquivo-chave.
O ícone está presente tanto na barra de status do navegador de arquivos do PeaZip quanto na interface de extração de arquivos compactados; uma vez que a senha é definida, o ícone mudará de cor.

CRIAR ARQUIVO COMPACTADO
Do sistema
- clique com o botão direito nos objetos a serem compactados e clique em "Adicionar ao arquivo compactado" no menu de contexto ou no menu Enviar para. Isso abrirá o diálogo de confirmação de criação de arquivo compactado; mais opções estão disponíveis na aba "Avançado"; clique em OK para criar o arquivo compactado.
- alternativamente, arraste arquivos/pastas para a janela ou atalho do PeaZip; a mesma interface de criação de arquivo compactado será exibida.

Do PeaZip 
- selecione os objetos a serem compactados e clique no botão "Adicionar"; a mesma interface de criação de arquivo compactado será exibida.

ADICIONAR ARQUIVOS/PASTAS PARA ATUALIZAR ARQUIVO COMPACTADO EXISTENTE
Abra um arquivo compactado no PeaZip (por exemplo, com um clique duplo, ou arraste um arquivo compactado para a janela ou ícone do PeaZip), depois arraste os arquivos e pastas a serem adicionados no arquivo compactado (ou clique no botão "Adicionar" e use o menu de contexto do aplicativo para adicionar objetos ao arquivo compactado).
Isso abrirá o diálogo de confirmação de criação de arquivo compactado; clique em OK para atualizar o arquivo compactado existente.

CRIAR ARQUIVO COMPACTADO DIVIDIDO EM ARQUIVOS MENORES
Ao criar um arquivo compactado conforme explicado nos pontos anteriores, clique no menu suspenso "Volume único" para selecionar um tamanho para os arquivos de saída (volumes) nos quais o arquivo compactado será dividido.
A maioria dos tipos de arquivos compactados suporta esta opção.

CRIAR ARQUIVO COMPACTADO CRIPTOGRAFADO
Clique no ícone de cadeado para inserir uma senha e, opcionalmente, um arquivo-chave; o ícone está presente tanto na barra de status do navegador de arquivos do PeaZip quanto na interface de criação de arquivo compactado.
Para ocultar os nomes dos arquivos e diretórios contidos no arquivo compactado, marque "Criptografar também os nomes de arquivo"; observe que isso será aplicado apenas se o arquivo compactado for criado em um formato que suporte esta função, como 7Z e ARC.
Observe que na interface de criação de arquivo compactado, ao lado do ícone de cadeado, há um aviso para informar visualmente se a criptografia está definida e se o formato de arquivo compactado atual suporta criptografia.

CRIAR ARQUIVOS COMPACTADOS SEPARADOS
Adicione os objetos a serem compactados (com o botão "Adicionar" do PeaZip, ou pelo menu de contexto do sistema ou pelo menu Enviar para) e, antes de confirmar com "Ok", marque a opção "Adicionar a arquivos compactados separados".

CONVERTER ARQUIVOS COMPACTADOS
No PeaZip, selecione os arquivos compactados a serem convertidos e clique em "Converter" na barra de ferramentas ou no menu de contexto; arquivos e pastas que não são arquivos compactados também podem ser adicionados, sendo a diferença que os arquivos compactados são extraídos antes da etapa de compressão.
Usar a opção "Converter arquivos compactados existentes" em conjunto com "Adicionar a arquivos compactados separados" (padrão) realiza uma conversão em massa dos arquivos compactados listados; sem essa opção, a conversão de arquivo compactado tem como objetivo consolidar os dados de entrada em um único arquivo compactado, melhorando a eficiência da compressão por permitir a recompressão dos dados originais a partir de sua forma não comprimida.

CRIAR DIRETAMENTE ARQUIVOS COMPACTADOS EM UM FORMATO ESPECIFICADO E COM UM NÍVEL DE COMPRESSÃO ESCOLHIDO
Usando o procedimento "Integração ao sistema" no menu Opções, é possível habilitar entradas no menu de contexto para adicionar diretamente arquivos/pastas selecionados a um arquivo compactado ZIP, 7Z ou autoextraível.
Para os formatos ZIP e 7Z, também é possível habilitar entradas no menu de contexto para comprimir no nível mais rápido, normal ou ultra, ignorando o nível de compressão padrão para o formato selecionado.

GERENCIADOR DE SENHAS
O Gerenciador de Senhas é acessível pelo menu principal, em Ferramentas > Gerenciador de Senhas, ou pelo formulário de Senha, no menu suspenso à esquerda do campo Senha.
As senhas salvas podem ser selecionadas no menu suspenso à esquerda do campo de senha no formulário de Senha, ou podem ser copiadas do Gerenciador de Senhas para uso em qualquer outro aplicativo.
Se nenhuma senha mestre estiver definida para o Gerenciador de Senhas, a lista de senhas estará acessível sem solicitar autenticação; caso contrário, as senhas não serão exibidas até que o usuário se autentique corretamente.

CONFIGURAR O APLICATIVO
Opções > Localização (e em Opções > Configurações, primeira aba) permite definir o idioma do aplicativo.

SOBRE O PEAZIP

O PeaZip é um gerenciador de arquivos e arquivos compactados de código aberto: multiplataforma, disponível como software portátil e instalável para Linux (aplicativo neutro em relação ao desktop), macOS e Windows de 32 e 64 bits.

O PeaZip permite aplicar filtros de pesquisa múltiplos e poderosos ao conteúdo de arquivos compactados; criar e extrair múltiplos arquivos compactados de uma vez; criar arquivos compactados autoextraíveis; exportar a definição de tarefa como linha de comando; salvar layouts de compactação e extração; adicionar arquivos compactados e pastas aos Marcadores; verificar e abrir arquivos comprimidos e não comprimidos com aplicativos personalizados, etc...

Outros recursos: criptografia robusta, cópia segura de arquivos, divisão/junção de arquivos (abrangência de arquivo), exclusão segura de dados, comparação, soma de verificação e hash de arquivos, benchmark do sistema, geração de senhas aleatórias e arquivos-chave.
